## 🌟 نبذة عن التطبيق | Overview

تطبيق **Adblock** يوفر تجربة متكاملة لحظر الإعلانات والمتتبعات وحماية اتصال الشبكة، مع مميزات متقدمة تشمل:
1. **واجهة حظر إعلانات وسجل حماية حقيقي**: متابعة الإعلانات المحظورة، المتتبعات، وحجم البيانات الموفرة.
2. **التحكم الصامت عبر Shizuku**: تنفيذ أوامر النظام الشفافة لتحديد أو إلغاء أدوات الفلترة بدون Root.
3. **حزمة اختصارات الشاشة الرئيسية (25+ أيقونة)**: تخصيص الاسم والرمز، بما في ذلك خيار الأيقونة الشفافة الشبح (100% Invisible).
4. **شاشة قفل أمنية مموهة (شاشة قفل الجهاز)**: مع قفل PIN ونمط 3x3 خفي وإعادة توجيه صامت للإعدادات عند الخطأ.

## ✨ المزايا والخصائص الرئيسية | Key Features

### 🛡️ 1. واجهة حظر الإعلانات وحماية الـ DNS (Adblock & Private DNS)
- **لوحة قيادة تفاعلية (Dashboard)**: عرض معدّل الحظر اللحظي (99.8%)، إحصائيات الإعلانات والمتتبعات المحجوبة، حجم البيانات الموفرة، وزمن استجابة الـ DNS.
- **سجل الحماية المباشر (Live Protection Stream)**: اعتراض وحظر النطاقات الإعلانية الخبيثة والمتتبعات لحظياً (DoubleClick, Google Analytics, Taboola, AppsFlyer, etc.).
- **قواعد الفلترة والأمان (Filter Rules)**: قوائم حظر محدثة (AdGuard Base, EasyList Privacy, Malware Domains, Anti-Tracking Shield).
- **اختيار خوادم DNS خاصة**: خوادم AdGuard Family, Cloudflare 1.1.1.2, Google Secure DNS.

### ⚡ 2. التحكم الشفاف عبر Shizuku (Shizuku Integration)
- تنفيذ أوامر الشيل الصامتة في الخلفية باستخدام **Shizuku 13.1.5** بدون الحاجة لصلاحيات Root تقليدية وبدون أي إزعاج للمستخدم:
  - **تحديد التطبيق**: تفعيل أداة التصفية كموقع وهمي بضغطة زر.
  - **تحديد لا شيء**: تعتيم وتفريغ الموقع الوهمي فوراً.

### 📱 3. اختصارات الشاشة الرئيسية التكيفية والشبحية (Custom Launcher Shortcuts)
- نافذة منبثقة تفاعلية لتخصيص الاختصار قبل إرساله للشاشة الرئيسية للهاتف:
  - **تعديل الاسم أو إخفاؤه**: إمكانية إدخال اسم مخصص أو تركه فارغاً (Zero-Width Space) لإظهار اختصار غير مرئي على اللانشر.
  - **حزمة أيقونات متخصصة (25+ أيقونة)**:
    - 🕶️ **الأيقونة الشفافة الشبح (100% Invisible)**: باستخدام 1x1 Transparent Bitmap نقي بدون أي إطار أو قالب يفرضه اللانشر (One UI / HyperOS / MagicOS).
    - 🛡️ **أيقونات Adblock و DNS المتنوعة**: درع Adblock، حماية DNS، إيقاف إعلانات، مسح الإعلانات، حظر النوافذ، إعلانات الفيديو، حماية الخصوصية، تصفح آمن، تسريع التصفح، خادم DNS، جدار ناري، رادار التتبع، حظر الكوكيز، مكافحة البرمجيات، مفتاح الـ DNS، حجب المتتبعات، فلتر البنرات، إخفاء الـ IP، توفير الطاقة، تعزيز الفلترة، سلة الإعلانات، خزنة الأمان، بصمة المتتبع، إشارة آمنة، وضبط الخوارزمية.

### 🔐 4. شاشة قفل الجهاز والغرفة المخفية (Stealth Gate Lock Screen)
- شاشة قفل أمنية حقيقية تتطلب رمز PIN من 4 إلى 8 أرقام أو نمط 3x3 متخفي (Stealth Pattern).
- **آلية الوصول غير المرئية**:
  - الضغط السريع 7 مرات على نص الإصدار في قسم "حول".
  - الضغط المطول على عنوان التطبيق العلوي (900ms).
- **إعادة التوجيه الصامت**: عند إدخال رمز خاطئ لعدد المحاولات المسموحة، يتم توجيه المستخدم صامتاً إلى إعدادات أندرويد الرسمية لتمويه وجود الواجهة المخفية.

### 🌍 5. الدعم اللغوي والسمات (I18N & Themes)
- دعم كامل للغتين العربية (RTL) والإنجليزية (LTR) مع التبديل التلقائي.
- دعم السمة الليلية (Dark Mode) والسمة النهارية (Light Mode).
